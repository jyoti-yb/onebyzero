# IMD Rainfall Data Intake

This directory is reserved for the official IMD 0.25-degree daily gridded
rainfall observation needed for the smoke test.

Required observation:

- Observation ending: 2026-09-27 08:30 IST
- Corresponding UTC period: 2026-09-26 03Z to 2026-09-27 03Z
- Product: official IMD 0.25-degree daily gridded rainfall
- Supporting information: the associated control file or schema documentation,
  including the date convention, grid layout, units, data type, and missing-value
  convention

Do not place substitute ERA5, GPM, or IMDAA observations in this directory.
No sample or fabricated observations should be used.
